# NURBS, surface and BRep engine qualification

**Audit initiated:** 2026-10-17. **Status:** architectural selection with bounded regression coverage, **not** a head-to-head performance benchmark or a claim of Rhino/Fusion parity.

Worldwright is the product and BuilderCraft is the repository. WorldBuilder and SolidCraft are modeling *workflows* in the unified Worldwright document; this audit also considers the independently developed open-source [SolidCraft application](https://github.com/tangency-labs/solidcraft) as a **real, separate CAD engine candidate**. These are distinct uses of the SolidCraft name. They must not be conflated.

## Source-pinned evidence, not marketing equivalence

- Worldwright baseline: `cameronprops/BuilderCraft` at `a7b581a156b8129088598beef32568b9287c5b89`. Native Rust `cadcraft_geom::nurbs3d::{Curve,Surface}` provides bounded rational NURBS evaluation without trims, topology or solids. The dedicated OCCT worker in `evaluations/cadrum`, called through `brep.*`, provides persisted exact BRep solids, primitive creation, Booleans, native inspection, STEP, and derived disposable display tessellation. The worker is currently the **only live exact-solid authority**; OCCT source/packaging, some degeneracies and complex surfacing are still open.
- [SolidCraft](https://github.com/tangency-labs/solidcraft) reviewed at upstream `a11446fd17d64ba7661da86407cb04d8432cbb7a`: `crates/kernel/Cargo.toml` depends on `truck-modeling`, `truck-shapeops`, `truck-meshalgo`, `truck-stepio`, `truck-topology`, with significant SolidCraft-owned fillet, shell, surface, STEP/IGES, topology identity and meshing code. `crates/sketch` is its own constraint solver. `docs/oracle.md` currently **reports 82/82 reference cases passing**, 61 analytic and 21 FreeCAD-derived, comparing volume, area, center of mass, extents, optional sampled surface distance, and STEP roundtrips. This is **upstream-reported acceptance**, not independently reproduced Worldwright results. The source gives typical relative area/volume error tolerances of `1e-3`, not arbitrary exact-math equivalence.
- [Truck](https://github.com/ricosjp/truck) is the Rust BRep topology/surface/Boolean foundation beneath SolidCraft. Benchmark SolidCraft's *patched/integrated* version, not just bare Truck; its behavior is not implied by unmodified Truck results. Worldwright's older truck probe is not an integrated replacement.
- [FreeCAD](https://github.com/FreeCAD/FreeCAD) is both a useful feature-history/sketch reference and an independent **OCCT-based** reference runner, not an independent mathematical BRep implementation. [Curvo](https://github.com/mattatz/curvo) offers candidate rational NURBS/surfacing functions, not verified as faster or more accurate in Worldwright. [cadcore](https://github.com/YATSKOVSKYI/cadcore) is a further Rust BRep candidate without qualified replacement evidence.
- The [Worldwright candidate register](../dependencies/OPEN_SOURCE_REUSE_CANDIDATES.json), [BRep candidates](../dependencies/BREP_AND_DEMO_BACKEND_CANDIDATES.json) and [integration register](OPEN_SOURCE_INTEGRATION.json) remain authoritative for broader dependency statuses. A roadmap entry or an experimental branch is not a shipped integration.

## Provisional winners by operation

| Operation | Selected production authority / source of reuse | Why, and what remains unqualified |
| --- | --- | --- |
| Trimmed BRep solid, Boolean, native STEP | **Worldwright's single OCCT worker** | Already authoritative and transactionally isolated in Worldwright; broad industrial topology/trim ecosystem. Tangencies, slivers, healing, trimmed NURBS interchange, multi-solid accuracy, native distribution and comparative speed are not certified. |
| Direct freeform NURBS curve/surface controls | **Worldwright rational f64 geometry** (until differential validation) | Direct source editing/serialization, no C++ roundtrip or duplicate shape ownership. Sparse span-local basis evaluation reduces arithmetic/allocation and preserves mathematical endpoints; benchmark Curvo and SolidCraft/Truck before choosing additional fitting, blending or splitting routines. No trimming in this representation. |
| Sketch constraints, feature recomputation, assembly identity | **Study/adapt bounded SolidCraft code behind Worldwright's shared command/history contracts** | Its independent Rust constraint solver and documented oracle corpus are considerably richer than Worldwright's implemented feature-history solid operations. Do not graft a second document model or secretly have its Truck solids replace existing OCCT solids. |
| NURBS-to-trimmed-solid loft/sweep/fillet/shell/offset | **OCCT exact operations first; evaluate SolidCraft techniques per feature** | Worldwright lacks verified end-to-end implementations. Require seam continuity, boundary mapping, topology validity, adjustable tolerances, and STEP roundtrip before promotion. |
| BRep shaded/wireframe display | **OCCT derived mesh only for OCCT solids** | Never use proxy triangles as exact manufacturing topology. Investigate SolidCraft's shared-edge display tessellation for efficiency; no replacement before identical tessellation-error/edge-conformity fixtures. |
| Organic scenery, mesh repair, rockwork | **Worldwright mesh topology + explicit mesh/implicit engines** | [Blender BMesh](BLENDER_BMESH_ADOPTION.md) inspires edit topology; [OrcaSlicer](https://github.com/SoftFever/OrcaSlicer) is a mesh/fabrication reference; [Manifold](https://github.com/elalish/manifold) is mesh CSG, [libigl](https://github.com/libigl/libigl) mesh numerical algorithms, and [Fidget](https://github.com/mkeeter/fidget) implicit surfaces. **None replaces exact trimmed BRep or rational NURBS source**. |
| 2D predicates, polygon triangulation and spatial queries | **Existing robust / rstar as applicable; evaluate Spade, geo, Parry narrowly** | [georust/robust](https://github.com/georust/robust) is integrated, [rstar](https://github.com/georust/rstar) is already used; [Spade](https://github.com/Stoeoef/spade) is a constrained planar triangulation candidate, [geo](https://github.com/georust/geo) GIS/polygons, [Parry](https://github.com/dimforge/parry) collision/distance, not replacements for geometric construction. |
| Interchange and reconstruction | **Native exact shapes + explicit adapters** | [openNURBS](https://github.com/mcneel/opennurbs) and rhino3dm provide 3DM data interchange, **not** the proprietary Rhino modeling kernel; OpenNurbsFit may inform fitting after license/quality review. STL/OBJ/tobj/stl_io, LAS, GLB and xatlas/meshoptimizer serve explicit I/O or preview work, not exact BRep creation. |
| Interface or workflow-only candidate | **No new geometry authority** | CADCraft, ArtCraft, GIMP, Photon Studio, egui-snarl and Vello support shell, graph, scene or drawing operations; StructureGraph supplies host-dependent design recipes. None should duplicate solid math. |

**Decision:** maintain **one OCCT exact BRep authority** today; maintain an independently editable native NURBS *source representation* for pure curves/surfaces, with explicit, tested conversion to OCCT when trims or solids are required. This is two different geometry *representations*, **not** two engines competing for the same solid. Prioritize copying/adapting *useful SolidCraft feature and sketch behavior* over retaining its entire alternate Truck scene/document/solid stack. **Revisit the decision if measured accuracy, speed, portability or LGPL distribution costs overturn it.**

## Numeric and performance acceptance gates

Do not select a new source from command counts, self-reported success rates, feature claims or a single synthetic speedup.

| Gate | Shared differential fixture | Required reporting |
| --- | --- | --- |
| Exact curve / surface | Clamped/nonclamped/repeated knots, weighted quarter-circle/cylinder, degree 1..5, trim boundaries, periodic seam, near-zero spans, unit rescaling, mirrored/reflected basis | Domain, endpoint error, normalized weight/basis sum, positional and tangent/curvature error in units and scaled tolerances; reject nonfinite and invalid inputs. |
| Construction | Planar/holey extrude, variable sections, loft, guide-rail sweep, offset, blend, fillet, shell, tangent and near-tangent contacts, self-intersecting profiles | Volume, area, center, extent, signed normal orientation, closed-manifold/edge counts, seam gaps, finite trims, predictable refusals. |
| Booleans | Two boxes, overlapping/tangent/identical solids, sphere against box, coincident cylinders, disjoint intersection, thin slivers, multiple bodies, nested voids | Shape count, orientation, analytic or FreeCAD/OCCT oracle measurements, identity/topology map, absence of crashes or silent fallback, unchanged source after error. |
| Exchange | STEP and BRep read/write/read; NURBS face with inner trim; units mm/m/in, axes, names, materials, compound/assembly | Bounded physical error, face/edge/topology preservation and explicit loss reports. Display STL/GLB is not an exact roundtrip. |
| Performance | 1, 100, 1,000 surfaces/bodies, complex assembly, cold/warm rebuild and targeted parameter change | Wall time median/p95, peak RSS, allocated bytes, GPU VRAM, worker startup, cache hit/miss, cancellation, per-operation/scene resident bytes and repeated-run variance, at matched Rust release build and machine. |
| Platform & licensing | Linux, Windows, macOS, Haiku where viable; WASM-specific native exclusions | Build/test parity; worker executable packaging, attribution, exact source licenses, source availability and relinking obligations. |

Use an immutable fixture corpus with both analytic values and independent reference bodies. Prefer hard failures to invalid geometry or unexpected representation conversion. `1e-3` is a useful upstream benchmark convention, **not** a manufacturing precision guarantee; establish feature-specific absolute, relative and angular tolerances using model units and local scale. Curvature continuity (G0/G1/G2) and offset self-intersections need dedicated geometric checks.

## Implemented in this qualification increment

- `crates/geom/src/nurbs3d.rs` now evaluates only the active knot span using bounded stack arrays for polynomial bases (degree <= 5). `Surface::evaluate` computes the U and V bases once per evaluation and uses only active tensor-product control points. Right endpoints are evaluated as the actual knot endpoint, rather than `b - 1e-12*(b-a)`. Added rational-cylinder, repeated-knot/partition-of-unity and exact-endpoint regression tests.
- `evaluations/cadrum/src/lib.rs` adds independent OCCT analytic baselines using SolidCraft oracle cases 01 (40 x 30 x 20 box), 02 (r15 x 50 cylinder) and 03 (60 x 40 x 20 box with a centered r6 through-hole). This checks identical **mathematical specifications**, not SolidCraft's result buffers, time or RAM; native CI must pass before recording it as validated.
- Existing NURBS preview tessellation is still uniform and explicitly not error-certified; exact BRep display still uses OCCT tessellation. No Truck, SolidCraft or Curvo runtime dependency was added, and none is promoted without common acceptance fixtures.
- These changes need current-branch Rust 1.95 CI before they can be described as passing. There is no local Rust toolchain in this development runtime.

## Next measured promotion, not a rewrite

Export a **shared input/expected-output fixture bundle** in machine-readable form for the 82-case SolidCraft oracle subset where equivalent Worldwright operations actually exist; run same cases against OCCT worker in CI with declared unit/tolerance and record results. Only after parity results add microbenchmarks and memory caps. Separately evaluate SolidCraft sketch solver and safe, independent formula/recompute modules against Worldwright's shared command/OrbWeaver operation contract. Preserve file-level license notices and verify the actual revision of copied code.
